# 前端组件

## 1. 结构总览

```
src/
  main.tsx        React 入口
  App.tsx         主组件：状态、地图、维度列表、标记、状态栏
  tileLayer.ts    CachedTileLayer：自定义瓦片层
  styles.css      全局样式（深色主题）
```

组件数量少是刻意的：功能集中在 `App.tsx`，唯一需要独立抽象的是瓦片加载逻辑（因为要重写 Leaflet 的 `GridLayer`）。

## 2. `App.tsx`

### 2.4 关键函数

| 函数 | 职责 |
|------|------|
| `ensureMap()` | 惰性创建 Leaflet 地图（`CRS.Simple`，zoom 0..4） |

| `drawMarkers(map, world, dim)` | 绘制当前维度的路径点与玩家位置 |
| `loadWorld(path)` | 调用 `open_world`，设置状态与视口 |
| `switchDim(id)` | 切换维度并飞到该维度的首个标记或原点 |
| `applyYmax(v)` | 应用高度切层 |
| `pickFolder()` | 打开目录选择对话框 |

### 2.5 坐标系

使用 `L.CRS.Simple`，映射关系：

```
lat = -worldZ
lng =  worldX
```

zoom 0 时 1 瓦片 = 256 世界单位 = 256 方块。

### 2.6 深链

支持 `?save=<路径>` 查询参数，页面加载后自动打开该存档：

```
http://localhost:1420/?save=C%3A%5C.minecraft%5C...%5C新的世界
```

用途：自动化测试可在刷新页面后恢复世界，也便于手动分享。

## 3. `tileLayer.ts` — `CachedTileLayer`

继承 `L.GridLayer`，替代 `L.tileLayer` 以解决三个问题：

| 问题 | 原生 `L.tileLayer` 的行为 | `CachedTileLayer` 的解法 |
|------|--------------------------|------------------------|
| 平移/缩放时出现空白洞 | 瓦片到达前显示空白 | 缓存 + 父瓦片缩放占位 |
| 请求风暴 | 一次性发出所有可见瓦片请求 | 并发上限 6 + 队列 |
| 重复请求丢失回调 | — | `waiting` 订阅列表，全部通知 |

### 3.1 内部字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `cache` | `Map<string, ImageBitmap>` | 已解码瓦片 |
| `empty` | `Set<string>` | 服务端标记为"无数据"的瓦片 |
| `waiting` | `Map<string, Array<cb>>` | 同一瓦片的待通知回调 |
| `queue` | `Array<() => void>` | 待执行请求 |
| `active` | `number` | 进行中的请求数 |
| `failures` | `Set<string>` | 失败的瓦片，避免无限重试 |
| `urlTemplate` | `string` | 当前 URL 模板 |

### 3.2 加载流程

```
load(key, url, onReady)
  ├─ 命中 cache        → 立即回调
  ├─ 已在 waiting      → 追加回调（关键：不丢弃）
  ├─ 已知失败          → 回调 null
  └─ 否则
       ├─ waiting.set(key, [onReady])
       └─ 入队 → fetch(url, {mode:"cors"})
            ├─ 读 X-Tile-Empty 头
            ├─ createImageBitmap(blob)
            ├─ cache.set(key, bitmap)
            └─ 通知所有 waiting 回调
```

### 3.3 父瓦片占位

`createTile()` 中，若 `z > 0` 且父瓦片（`z-1`，坐标减半）已缓存，则先把它放大 2 倍并裁剪到当前象限绘制到 canvas，同时 `opacity: 1`。清晰瓦片到达后覆盖重绘。

效果：缩放时地图保持连续（模糊），而不是出现空洞。

### 3.4 空数据标记

若响应头 `X-Tile-Empty: 1`，绘制 16px 棋盘格（`rgba(255,255,255,0.035)` / `0.07`），表示"该区域从未生成"。

与"加载中"的区别：加载中是透明（或父瓦片模糊图），无数据是可见棋盘格。

### 3.5 诊断接口

`stats()` 返回 `{cached, waiting, queued, active, failed, empty}`，通过 `window.__tileLayer` 暴露，供自动化测试断言。

## 4. 样式

`styles.css` 采用深色主题，主要区块：

| 类名 | 说明 |
|------|------|
| `.app` | 纵向 flex 布局（顶栏 / 主体 / 状态栏） |
| `.topbar` | 标题、存档信息、操作按钮 |
| `.sidebar` | 维度列表、高度滑块、图例、来源统计 |
| `.mapwrap` / `.map` | 地图容器 |
| `.statusbar` | 坐标、维度、层、存档名 |
| `.error` / `.loading` | 悬浮提示 |
| `.sources` | 路径点来源统计列表 |
