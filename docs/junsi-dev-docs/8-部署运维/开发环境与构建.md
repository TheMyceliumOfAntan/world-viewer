# 开发环境与构建

## 1. 环境要求

| 组件 | 版本 | 说明 |
|------|------|------|
| Node.js | 24.x | 实测 v24.19.0 |
| pnpm | 11.x | **必须用 pnpm，不要用 npm**（见 §1.1） |
| Rust | 1.97+ | MSVC 工具链 |
| WebView2 | 152+ | Windows 10/11 自带 |

### 1.1 为什么用 pnpm 而不是 npm

本机实测：`npm install` 安装 devDependencies 时**连续两次超时**（600s 无输出），但 `npm view` 2 秒即返回、缓存校验通过、认证正常。同一网络下 `pnpm install` 23 秒完成。

现象特征：`package-lock.json` 写入了记录，但 `node_modules` 未落盘，状态不一致。

**结论**：本项目所有 JS 依赖操作用 pnpm。`package-lock.json` 已删除，改用 `pnpm-lock.yaml`。

## 3. 命令

```bash
# 依赖安装
pnpm install

# 开发（Vite + Tauri，热重载）
pnpm tauri dev

# 仅前端构建（类型检查 + 打包）
pnpm build

# Rust 检查与测试
cd src-tauri
cargo check
cargo test
cargo test -- --nocapture        # 含性能/覆盖率输出

# 打包（生成 .msi / .exe）
pnpm tauri build
```

## 4. 调试

### 4.1 前端调试（CDP）

```powershell
$env:WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS = '--remote-debugging-port=9223'
Start-Process 'src-tauri\target\debug\world-viewer.exe'
```

然后用 `http://127.0.0.1:9223/json/list` 获取目标，Node 内置 WebSocket 直连。详见 `4-编码规范/测试与验证.md`。

> 端口 9222 常被其他 WebView2 应用占用（如网易 GameViewer），统一用 9223。

### 4.2 深链打开存档

```
http://localhost:1420/?save=<URL 编码的存档路径>
```

刷新页面即可恢复世界，便于反复调试同一存档。

## 5. 项目约定

### 5.1 代码风格

- **注释**：只在解释"为什么"时写。解释"这段代码在做什么"的注释一律删除。
- **不引入未确认的依赖**：能用标准库就用标准库。
- **外科手术式改动**：不顺手重构无关代码。
- **行尾**：新建文件用 CRLF；编辑现有文件保持原样。Git 配置 `core.autocrlf=true`。

### 5.2 关键约束（违反会导致功能静默失效）

| 约束 | 原因 |
|------|------|
| 协议处理器必须 `std::thread::spawn` | 同步渲染阻塞事件循环，窗口卡顿 |
| `color_ref()` 只返回方块 id 名 | 返回显示名会让染色分类恒 false |
| 瓦片 URL 必须含 `worldKey` | 否则切换存档复用旧瓦片 |
| `is_foliage` 不得包含花朵/作物 | 会把红花染成绿色 |
| 存档目录只读 | 红线，不得写入 |

### 5.3 提交信息

遵循 Conventional Commits，中文描述：

```
<type>[scope]: <描述>

[正文]

[页脚]
```

type：`feat` / `fix` / `perf` / `refactor` / `docs` / `style` / `test` / `chore`

正文说明**为什么**而非**怎么做**，每行 ≤72 字符。
