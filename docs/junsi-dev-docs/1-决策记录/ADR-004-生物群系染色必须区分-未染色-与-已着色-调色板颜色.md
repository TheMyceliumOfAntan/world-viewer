# ADR-004：生物群系染色必须区分"未染色"与"已着色"调色板颜色

| 属性 | 内容 |
|---|---|
| 状态 | 已采纳 |
| 日期 | 2026-09-16 |
| 决策者 | AI Agent |

## 背景

引入真·生物群系染色时，把调色板颜色一律乘以 biome tint（原版 (base*tint)>>8 公式），结果水面变成近黑。原因：JourneyMap 调色板对不同方块存的颜色性质不同——草/树叶存的是未染色的灰度纹理色（#939393，需要乘 tint 上色），而水（#2e43f4）、芦苇（#94c065）、模组树叶已经是最终色（不需要上色）。对已着色颜色再乘一次 tint 会把它压暗到不可辨认。这个差异在引入群系染色前不存在，因为旧实现只用固定平原绿对灰度方块染色，没有触及已着色方块。

## 决策

按调色板颜色是否灰分派两条公式。判定用 biome::needs_tint(c)：max(c)-min(c) <= 24 视为灰色（未染色），用原版 (base*tint)>>8；否则视为已着色，用相对平原基准的比例缩放 (base * tint / plains_tint)，保留亮度只换色相（例如沼泽水变绿但仍明亮）。阈值 24 覆盖了调色板的灰阶抖动（实测草 #939393、树叶 #918e86 色差 11）。

## 备选方案

### 方案 一律乘 tint（原版公式）
- 优点：实现最简单，与 MCA Selector 完全一致
- 缺点：已着色方块被二次压暗，水变近黑，视觉严重退化
- 为何不选：拒绝：MCA Selector 的颜色表对水存的就是灰色基色（b0b0b0），与本项目用 JourneyMap 已着色调色板的现实不同，不能直接照搬

### 方案 只对白名单方块染色，其余不动
- 优点：无需颜色判定，行为可预测
- 缺点：模组方块数量巨大，白名单永远不全；且不同模组对同一方块是否预染色的做法不一致
- 为何不选：拒绝：无法维护

### 方案 按颜色是否灰分派两条公式
- 优点：自适应任意调色板，无需维护方块名单；对模组方块天然正确
- 缺点：阈值 24 是经验值，理论上存在边界方块误判
- 为何不选：采纳
