# 系统要求

## 1. 功能需求

### FR-1 存档加载
- 接受存档目录路径（含 `level.dat`），或通过目录选择对话框选取
- 支持 `?save=<路径>` 深链直接打开
- 只读打开，**绝不写入存档目录**

### FR-2 跨版本支持
| MC 版本 | 区块格式 |
|---------|---------|
| 1.7.10 | `Blocks16` + `Data16`（16 位 id） |
| 1.12.2 | `Blocks` + `Add` + `Data` |
| 1.13+ | `sections[].block_states`（调色板 + 位压缩） |

格式自动探测，无需用户指定。

### FR-3 模组支持
- 方块名映射：优先 `level.dat` 内的注册表，缺失时用内置原版表兜底
- 方块配色：优先 JourneyMap 调色板，缺失时用内置原版表 + 名称后缀规则
- 生物群系染色：对草地/树叶按原版染色类别施加绿色（否则显示为灰度纹理色）
- 维度命名：Galacticraft / GalaxySpace / 暮色森林 / ExtraUtilities / Witchery 等

### FR-4 多维度浏览
- 自动扫描 `region/` 与 `DIM*/region/`，仅列出有区块数据的维度
- 切换维度时视口飞到该维度的玩家位置或首个路径点

### FR-5 路径点
支持三种来源，自动合并，弹窗标注来源：
- JourneyMap：`journeymap/data/sp/<世界>/waypoints/*.json`
- Xaero：`xaero/{minimap,world-map}/<世界>/...`
- VoxelMap：`voxelmap/<世界>.points`

### FR-6 地图交互
- 平移、缩放（zoom 0..4，zoomSnap 0.25）
- 高度切层：滑块选择 Y 上限，查看地下结构
- 鼠标坐标显示
- 玩家最后位置标记

### FR-7 渲染表现
- 浮雕阴影（坡向光照）呈现地形起伏
- 无数据区域以棋盘格标记，与"加载中"区分
- 缩放/平移时以父瓦片模糊占位，不出现空洞

## 2. 非功能需求

### NFR-1 性能
| 指标 | 要求 | 实测 |
|------|------|------|
| 单瓦片渲染（zoom 0） | < 200 ms | 139.5 ms |
| 一屏瓦片（16 个） | < 1.5 s | 1055 ms |
| 交互期间主线程阻塞 | 无 >250ms 卡顿 | 0 个 long task |
| 单区块解析 | < 0.5 ms | 0.33 ms |

### NFR-2 资源占用
- 区块缓存容量 4096（约两屏多）
- 前端瓦片并发上限 6
- 无磁盘缓存（每次启动重新渲染）

### NFR-3 可靠性
- 存档目录只读，零写入
- 单区块解析失败不影响整瓦片渲染（跳过该区块）
- 缺失的调色板/路径点文件不导致崩溃

### NFR-4 可测试性
- 核心逻辑（解析、渲染、配色）可在无 GUI 环境下测试
- 暴露 `testing` 模块供集成测试调用
- 支持 CDP 远程调试驱动真实 UI

### NFR-5 配色质量
| 指标 | 要求 |
|------|------|
| 彩色像素占比（平原瓦片） | > 90% |
| 绿色植被占比（平原瓦片） | > 30% |
| 灰阶占比 | < 10% |

实测：98.5% 彩色 / 39.3% 绿色 / 1.5% 灰阶。

## 3. 运行环境

| 组件 | 最低版本 |
|------|---------|
| Windows | 10（需 WebView2） |
| WebView2 Runtime | 152+（Win11 自带） |
| 内存 | 建议 4 GB 可用 |
| 磁盘 | 约 500 MB（构建产物 + 依赖） |

## 4. 范围外（明确不做）

| 项 | 原因 |
|----|------|
| 写入存档 | 红线：只读 |
| 从 jar 提取纹理 | v1 范围外；颜色用调色板 + 内置表 |
| 磁盘瓦片缓存 | v1 范围外 |
| 悬停显示方块信息 | v1 范围外 |
| 生物群系精确着色 | 需读 colormap 温度/湿度，待办 |
| 实体/生物渲染 | 仅渲染方块地表 |
